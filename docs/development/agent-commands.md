# Agent command reference

Generated by `tools/generate_agent_protocol.py` from
`scripting/api/agent-protocol.json`; do not edit by hand. Protocol semantics
are described in [agent-protocol.md](agent-protocol.md).

Protocol version: 2.

## `describe`

Report the protocol version, command schemas, execution limits, registered component types and the curated Lua host API.

Access: `read`.

No parameters.

## `observe`

Return the current frame, scene, running state and every live actor with world position and supported component properties, without advancing time. Optional bounded tilemap cell queries.

Access: `read`.

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `tilemaps` | object[] (max items 16) | no | At most 16 queries and 256 cells in total. |

## `step`

Advance fixed 1/60 s ticks with the given held input, then observe.

Access: `simulate`.

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `frames` | integer (≥1, ≤3600) | no | Default 1. |
| `keys` | string[] (max items 512) | no | Complete held key set as SDL key names (for example "right", "space", "e"). Omit to keep the previous held keys; [] releases all keys. Edges occur once at the start of the request. |
| `mouse` | object | no | Screen-space mouse state. Omitted x/y/buttons are retained; buttons is the complete held set (1 left, 2 middle, 3 right); wheel applies on the first tick only. |

## `run_until`

Advance ticks with the given held input until any condition holds after a tick, gameplay stops, or max_frames elapse, then observe. The response's run_until reports the reason, frames advanced and matched condition index.

Access: `simulate`.

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `max_frames` | integer (≥1, ≤36000) | yes |  |
| `until` | value[] (min items 1, max items 16) | yes |  |
| `keys` | string[] (max items 512) | no | Complete held key set as SDL key names (for example "right", "space", "e"). Omit to keep the previous held keys; [] releases all keys. Edges occur once at the start of the request. |
| `mouse` | object | no | Screen-space mouse state. Omitted x/y/buttons are retained; buttons is the complete held set (1 left, 2 middle, 3 right); wheel applies on the first tick only. |

## `reload_scripts`

Atomically reload the source files of registered Lua component types at idle, keeping instances and state; does not advance a tick or rerun OnStart.

Access: `modify`.

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `types` | string[] (min items 1, max items 64) | yes |  |

## `reset`

Start a new runtime worker and reload the project, applying the seed before any script runs. Omitting seed keeps the current one.

Access: `simulate`.

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `seed` | integer (≥0, ≤4294967295) | no |  |

## `quit`

Stop the runtime and end the session.

Access: `session`.

No parameters.
